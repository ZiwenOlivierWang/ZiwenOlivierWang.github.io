# Source Serif 4

These unmodified WOFF2 files are the Source Serif 4 fonts previously downloaded
by `next/font/google` for this site. Keeping them in the project preserves the
existing appearance and removes font downloads from development and builds.

The files cover normal and italic styles at weight 500, with Latin,
Latin Extended, Greek, Cyrillic, Cyrillic Extended, and Vietnamese subsets.
Their original Unicode ranges and fallback metrics are declared in
`src/app/fonts/source-serif-4.css`.

Upstream: https://github.com/adobe-fonts/source-serif
