# University logo sources

These assets are copied unchanged from the three files supplied by the site owner. They are stored locally so the About page does not rely on external image hosts.

- `unc.svg`: `interlocking-nc-carolinablue-navy-rgb.svg`, SVG viewBox `0 0 144 112.63`.
- `tsinghua.jpg`: `Tsinghua.jpg`, original dimensions 1400 × 600.
- `cufe.svg`: `CUFE.svg`, SVG viewBox `0 0 88 89`.

The About renderer scales every logo uniformly. For the Tsinghua JPG, a 440 × 440 display window starting at (466, 75) hides the surrounding whitespace using CSS; the original file and the seal's proportions are preserved.

All marks belong to their respective universities.
